# CurveLoupe

A bigger graph editor for DaVinci Resolve.

I made this because a friend was wasting time on Fusion’s tiny graphs. Same curve, bigger window, writes back to your keyframes.

**[Site / download](https://sinj0x7.github.io/kinetiq)**

## Install

Download [CurveLoupe.zip](https://sinj0x7.github.io/kinetiq/CurveLoupe.zip), unzip it, copy the `curveloupe` folder here:

| OS | Path |
|---|---|
| Windows | `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Comp\` |
| macOS | `~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Comp/` |
| Linux | `~/.local/share/DaVinciResolve/Fusion/Scripts/Comp/` |

Restart Resolve. Fusion page → animated tool → **Workspace > Scripts > curveloupe > CurveLoupe**.

Windows needs [Python 3](https://www.python.org/downloads/) for Resolve scripting.

More in [`curveloupe/README.md`](curveloupe/README.md).
